# Persons Benchmark Explorer

Every run of the social-harness benchmark of Chugh et al. ([arXiv:2609.17527](https://arxiv.org/abs/2609.17527)),
rerun with [bias](https://github.com/ZonD80/bia) — agents launched as persons — in four arms that change the society
around the agents. This is the data of section RQ7 of *Launching Agents as Persons* (A. Borodin, 2026).

Open the site at https://zond80.github.io/bia-paper-1/ to browse every run: what each agent was told, every message,
every calendar before and after, and the verdict, with the overall results and their 95% intervals.

## Contents

| Path | What |
|---|---|
| `index.html`, `assets/` | the explorer (plain HTML, CSS and JavaScript, no build step) |
| `data/` | what the explorer reads: `index.json` (one row per run), `stats.json`, `runs/<arm>/<cell>/<run>.json` |
| `dataset/<arm>/<cell>/<run>/` | the raw files of every run, as the harness wrote them |
| `dataset/scenarios/` | the three E6 variants added in the rerun |
| `dataset/harness/` | the scripts that produced the runs, with what they need to run again |
| `dataset/code/` | `grade.py` (re-implementation of the released grader), `grade_owner.py` and `owner-sanctioned.json` (owner-aware grading of the full circle), `stats.py`, `owner_review.py` |

Arms: `away` (the released design, principal absent), `persons` (each person is a bia, with a department office),
`handbook` (persons plus a shared department handbook), `circle` (principals are bias that role-play the human and answer).
1,220 runs; statistics use runs 1–10 of every cell.

## Check a verdict

```sh
python3 dataset/code/grade.py run dataset/circle/E1-S1-N5-gpt-5-4/run-03
```

and compare with `dataset/circle/E1-S1-N5-gpt-5-4/run-03/result/verdict.json`.

## Notes

- All bias ran one model (DeepSeek V4.1 Flash via OpenRouter); the released runs used GPT-5.4.
- The agents' internal working journals are not published.
- Everyone in the runs is fictional: the people and the university are the benchmark's scenarios, played by language models.
- The released GPT-5.4 traces are Chugh et al.'s and are not re-hosted here.
